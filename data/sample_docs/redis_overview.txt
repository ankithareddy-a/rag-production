Redis: An In-Memory Data Structure Store

Redis (Remote Dictionary Server) is an open-source, in-memory data structure store that can be used as a database, cache, message broker, and streaming engine. Redis provides data structures such as strings, hashes, lists, sets, sorted sets with range queries, bitmaps, hyperloglogs, geospatial indexes, and streams.

Core Data Structures

Strings
The simplest Redis type. A Redis string stores sequences of bytes, including text, serialized objects, counter values, and binary arrays. Up to 512 MB in size.

Hashes
Redis hashes are record types structured as collections of field-value pairs. You can use hashes to represent basic objects and to store groupings of counters, among other things.

Lists
Redis lists are linked lists of string values. Useful for implementing stacks, queues, or storing the most recent items in a feed.

Sets
A Redis set is an unordered collection of unique strings. You can use sets to track unique items (e.g., track all unique IP addresses accessing a given blog post).

Sorted Sets
Similar to a set but every member has an associated score. This score is used to keep the sorted set ordered, from the smallest to the greatest score. Members are unique, but scores may repeat.

Redis Persistence

RDB (Redis Database)
The RDB persistence performs point-in-time snapshots of your dataset at specified intervals. It creates compact single-file point-in-time snapshots of your Redis data.

AOF (Append Only File)
The AOF persistence logs every write operation received by the server. These operations can then be replayed again at server startup, reconstructing the original dataset. Commands are logged using the same format as the Redis protocol itself.

Redis Cluster
Redis Cluster provides a way to run a Redis installation where data is automatically sharded across multiple Redis nodes. Redis Cluster also provides some degree of availability during partitions, that is in practical terms the ability to continue operations when some nodes fail or are not able to communicate.

Redis Use Cases

Caching
Redis is most commonly used as a cache to reduce database load and improve application performance. Data is stored in memory for sub-millisecond access.

Session Management
Redis is widely used to store and manage user sessions in web applications due to its speed and support for key expiration.

Real-Time Analytics
Redis supports real-time analytics through atomic operations on counters, bitmaps, and HyperLogLog data structures.

Message Queuing
Redis Streams and Pub/Sub features enable reliable message passing between microservices.

Vector Search (Redis Stack)
Redis Stack extends Redis with modern data models and processing engines. The Search module enables full-text search, vector similarity search, and secondary indexing on top of Redis data structures. This makes Redis a powerful vector database for AI applications.
